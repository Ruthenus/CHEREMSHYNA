# Що дописано

## Перевірка сумісності (після Full Stack інтеграції)

- Знижка на день народження враховує перехід через Новий рік (сусідні роки, не лише поточний); «сирна п’ятниця» бере дату через `timezone.localdate()` у поясі `Europe/Kyiv`.
- Кількість у замовленні обмежена 99 на позицію і після склеювання однакових рядків. Текст швидкого замовлення — до 2000 символів.
- Фото товару віддається як відносний `/media/...`, а не `http://127.0.0.1:8000/...`, щоб відкривалось і з телефона, і через проксі Vite.
- Прострочений JWT більше не робить каталог «офлайн»: публічний запит повторюється без токена.
- Локальний приклад товарів не можна покласти в кошик: його id не збігаються з базою, кнопка «Купити» вимкнена.
- У кошику одиниця береться з підпису ціни (`₴/л`, `₴/банка`), а не завжди «шт».
- У кабінеті порожній телефон справді стирає номер (`phone: phone.trim()`), непорожній перевіряється як номер.
- Вихід піднімає `auth_revision` і, якщо передали refresh, гасить його через blacklist. Старий access одразу недійсний.
- Пароль реєстрації проходить валідатори Django. Мінімум лишився 6, як на формі.
- У кошику категорія українською за словником slug (`sausages` → «Ковбаси»), не сирий `SAUSAGES`.
- Сід ставить залишок **50**. Замовлення його зменшує і не проходить, якщо не вистачає.
- Швидке замовлення залогіненого клієнта прив’язується до нього і видно в кабінеті як заявку.
- Екран оформлення питає `POST /api/orders/preview/` і показує знижку до підтвердження. У базу preview не пише.
- Тексти акцій у кабінеті беруться з API (ті самі, що в сіді). Якщо API мовчить — лишаються запасні.
- Секрет без префікса `django-insecure-`. CORS на всі джерела лише при `DEBUG=True`. HTTPS-прапорці не вмикались: локальна здача йде по HTTP.

Теку `management` з окремого архіву перенесено в `back_end/catalog/management/`
(так Django знаходить команду `seed_data`). Окремою текою в корені її більше немає.

## Back End

| Файл | Навіщо |
| --- | --- |
| `config/urls.py` | Підключено auth, categories, products, orders, promotions. Був лише `/api/health/`. Додано Swagger, ReDoc і схему. |
| `config/settings.py` | `drf_spectacular` (пакет уже був у requirements, але не був увімкнений), `SIMPLE_JWT`, `.env` читається з теки `back_end`. |
| `catalog/views.py` | `?search=` шукає ще й опис. `?ordering=` реально працює (`OrderingFilter`). |
| `catalog/serializers.py` | `price` іде числом, не рядком `189.00`. `image` — відносний `/media/...`. |
| `catalog/urls.py` | Лише коментар, куди ці шляхи монтуються. |
| `catalog/management/commands/seed_data.py` | **Новий файл** (перенос). Сід писав у `icon`, а модель має `emoji`. Товарам не вистачало обов’язкових `slug` і `external_id`. Залишок у демо — 50. |
| `orders/serializers.py` | Переписано: старі поля `total_amount` і `price` у моделях не існують. Відповідь як у контракті. |
| `orders/views.py` | Свої замовлення, створення з цінами на сервері, `POST /orders/quick/` без авторизації, `POST /orders/preview/` без запису в базу. Знижка на день народження −15%, у п’ятницю −10% на сири. |
| `orders/urls.py` | `''`, `quick/`, `preview/`, `<id>/` замість роутера. `quick/` і `preview/` стоять вище за `<id>/`. |
| `promotions/serializers.py` | Прибрано неіснуючі поля й `PromoCode`. |
| `promotions/views.py`, `promotions/urls.py` | Прибрано в’юсет промокоду — моделі немає, Swagger через це падав би. |
| `users/serializers.py` | Вподобання для кабінету — українські підписи, у базі лишаються ключі `meat` / `cheese`. Дубль email — українською. |
| `users/views.py` | Схеми для Swagger. Blacklist токена: застосунок `token_blacklist` підключено в `INSTALLED_APPS`, тож refresh справді гаситься. |
| `users/backends.py` | Вхід за email без оглядки на регістр. |

Моделі, міграції, адмінка й верстка навмисно не переписувались.

## Front End

| Файл | Навіщо |
| --- | --- |
| `src/api.js` | **Новий шар.** axios, Bearer, `unwrapList`, усі маршрути контракту. На 401 з токеном один раз оновлює access; публічний каталог повторюється без токена. |
| `src/context/AuthContext.jsx` | Реєстрація, вхід, профіль, вихід і замовлення йдуть на Django. Паролі з localStorage прибрано. |
| `src/components/Products.jsx` | Каталог з API. Якщо сервер мовчить — лишається короткий локальний приклад, «Купити» вимкнено. |
| `src/components/Contacts.jsx` | Швидке замовлення: `POST /orders/quick/`. |
| `src/components/User/Cabinet.jsx` | Поля імені й телефону відкриваються вже заповненими. Порожній телефон стирає номер. Акції з API. |
| `index.html` | Мова `uk` і назва вкладки «Гастроном «Черемшина»» замість шаблону Vite. |
| `API_CONTRACT.md` | Абзац «прототип на localStorage» замінено на фактичний стан. |

Кошик як і раніше живе в браузері (`cheremshyna_cart`). На сервер він потрапляє лише в момент `POST /orders/`.

## Картка товару без фото

- Якщо в товару немає `image`, картка більше не показує сірий напис «Фото товару».
- Заглушка бере іконку категорії (`categories.icon` / emoji), запасний варіант — 🛒.
- У `App.css` оновлено `.card-image-placeholder`: градієнт замість пласкої плашки, додано `.card-image-emoji`.
- Гілка з `<img>` не змінена: фото з адмінки або сіда як і раніше має пріоритет.
